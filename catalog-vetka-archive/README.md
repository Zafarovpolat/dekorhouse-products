# Каталог VETKA — только фото из архива

Урезанная версия каталога `../catalog-vetka/`: те же вёрстка, титул и палитра,
но оставлены **только товары, чьё фото пришло из выгрузки чата от 31.07.2026**.

Собирается **только ebook-версия** — файл для телефона и мессенджеров.

| | |
|---|---|
| товаров | 61 |
| страниц | 15 (титул + 14) |
| размер | 5,2 МБ |
| файл | `catalog-vetka-archive-ebook.pdf` |

Фото используются **как есть**, без обработки: это кадры из магазина, с руками
и фоном помещения. Поскольку здесь нет обработанных вырезок из базы, страницы
выходят однороднее, чем в полном каталоге, где два типа картинок соседствуют.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | вёрстка, копия полного каталога |
| `products.json` | 61 товар: код, цена, картинка |
| `img/` | 61 фото из архива |
| `build-pdf.py` | HTML → PDF |
| `fix-pdf.py` | чинит ICC от Chromium; принимает `ebook` или `printer` |

## Товары

61 код: точные совпадения подписей из чата с базой плюс подтверждённая владельцем
привязка `Z-81/Z-82/Z-83` → `B-81/B-82/B-83`. Полный разбор — в `../vetka-archive-0731/`.

Серии: `B-2`, `B-10`, `B-80`, `B-81`, `B-82`, `B-83`, `B-85`, `B-86`, `B-88`,
`C-11`, `C-15`, `D-1`, `Z-21`, плюс одиночные `Anor`, `Black olive`, `Olive`,
`Olive no fruit`, `Z-30`, `Z-31`.

Цены и коды — из Supabase, категория `c5dbafbf74f984746b64e8644`, фильтр `inStock=true`.

## Как пересобрать

```bash
pip install playwright pypdf pikepdf pillow
python3 -m playwright install chromium

cd catalog-vetka-archive
python3 build-pdf.py        # → catalog-vetka-archive.pdf (сырой, не для клиента)
python3 fix-pdf.py ebook    # → catalog-vetka-archive-ebook.pdf
```

**Сырой PDF клиенту не отдавать** — Chromium вшивает `/ICCBased`, из-за чего
мобильные viewer'ы не показывают картинки. Подробно про это — в
`../catalog-vetka/README.md`. Сырой файл в репозитории не хранится.

Список товаров пересобирается скриптом `build-archive-only.py` (у агента) из
`../vetka-archive-0731/manifest.json` и `../catalog-vetka/products.json`.
