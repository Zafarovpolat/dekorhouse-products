# Сверка фото из архива чата · категория «ветка» · 31.07.2026

Страница для ручной проверки: какое фото из архива какому товару в базе соответствует.
Открыть `index.html`.

**Скрипт ничего не решает сам.** Где код из подписи совпал с кодом товара — привязка показана.
Где не совпал — показаны похожие товары как кандидаты, но привязки нет. Решение за человеком.

## Что требует решения

**1. Подписи `Z-81` / `Z-82` / `Z-83` — 15 фото.** Таких кодов в базе нет, есть
`B-81` / `B-82` / `B-83` с точно такими же цветами. Именно у этих `B-8x` сейчас
битые сырые фото, так что если это одни и те же ветки — архив закрывает главную
дыру в каталоге. На странице они стоят вплотную для сравнения.

**2. Пять подписей без совпадения:** `w-15`, `w-14`, `w-29`, `z-32`, `z-33`.
Рядом показаны похожие товары из базы.

**3. Дубль:** фото `#483` и `#486` подписаны одинаково — `z-82 purple`.

## Про `ref/` и битые ссылки

У 57 товаров категории картинка в базе указана на `cdn.bito.uz`, а этот хост
отдаёт HTML страницы админки вместо картинки — то есть ссылка нерабочая.
Рабочий адрес того же файла: `api.bito.uz/upload-api/public/uploads/...`.

Оригиналы по 1–1.5 МБ и грузятся медленно, поэтому для страницы они скачаны
и уменьшены в `ref/`. **В самой базе ссылки не менялись** — это только для просмотра.

## Как пересобрать

```bash
python3 build-review.py     # генерирует index.html + manifest.json, копирует фото
python3 fetch-refs.py       # скачивает и уменьшает картинки товаров в ref/
```

Скрипты лежат вне репозитория, у агента. Вход: `messages.html` и `photos/` из
выгрузки чата плюс выгрузка товаров из Supabase.
